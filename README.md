# FundLarper

A web tool for stress-testing and sanity-checking startup pitch ideas with AI.

Instead of only getting gentle feedback from friends, FundLarper runs a pitch through Google's Gemini API to simulate common investor pushback, skeptical customer objections, basic SWOT analysis, and possible fatal flaws before pitching to real people.

---

## What It Does

- **Pitch Teardown:** Takes a short description or an uploaded pitch deck (PDF/text) and generates:
  - A summarized elevator pitch rewrite
  - Simulated customer objections (why users won't switch from existing tools)
  - Simulated VC pushback (defensibility, distribution, unit economics)
  - Basic SWOT breakdown
  - Top potential failure modes / fatal flaws
  - A suggested 7-day no-code test to validate demand before building
- **Interactive Pitch Practice:** Chat with simulated investor personas (e.g., an angel investor, a YC-style partner, a skeptical enterprise buyer) to get grilled on specific aspects of the idea.
- **Evaluation Scorecard:** Generates heuristic ratings across 8 dimensions (competitors, moat, profitability, market size, target audience, scalability, capital required, defensibility).

---

## ⚠️ Limitations & Reality Check

Let's be real about what this tool is and isn't:

1. **It is an LLM, not a real VC:** The critiques, objections, and radar charts are based on prompt engineering with Gemini (`gemini-2.5-flash`). It doesn't have access to proprietary market data, real user demand, or actual venture dealflow.
2. **The scores are arbitrary heuristics:** The numeric ratings (out of 100) and tier labels are generated by the prompt to provide a quick comparative summary. Do not base actual financial or life decisions on an AI scorecard.
3. **PDF text extraction is basic:** It uses `pdf-parse` for pitch deck uploads. If your deck relies heavily on graphics, unusual layouts, or scanned images, text extraction may be messy or incomplete. Plain text input is always more reliable.
4. **Offline fallback is repetitive:** If you don't supply a Gemini API key, the app falls back to a hardcoded template engine so you can still preview the UI, but the generated insights will be generic and repetitive.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) 15 (App Router) + React 19
- **Styling:** Tailwind CSS
- **AI Integration:** Google Gemini API (`gemini-2.5-flash`)
- **Icons & Extras:** Lucide React, Canvas Confetti

## Getting Started

### Prerequisites

- Node.js 18+ and npm
- (Optional) A [Google Gemini API Key](https://aistudio.google.com/) for live AI evaluations.

### Installation

```bash
git clone https://github.com/yeashaswi/FundLarper.git
cd FundLarper
npm install
```

### Environment Setup

Create a `.env.local` file in the root directory:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

*(If you don't add an API key, the app will run using built-in mock evaluation templates.)*

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3005](http://localhost:3005) in your browser.
